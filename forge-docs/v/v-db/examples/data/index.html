Doors, comma filters, named sets

Section titled “Doors, comma filters, named sets”

The code adversarial analysis landed sixteen ruled fixes on 2026-08-15; this section executes the ones a user meets at the command line. Transcripts captured at the head of that series (host commit 4d5d3c9 plus the absent-file fix below), vehu live where an engine answers.

A comma in a --where value is data. VistA names are comma-shaped, and before this series rows/find split the value into two predicates (count/distribution never did). Now all of these verbs take the clause byte-for-byte — filtered 1 below is POSTMASTER, whose name carries no comma:

A named --files set never sweeps the instance. One single-file census per named file (seconds), and a file the instance does not have is reported — the engine's own U-VSL-DD-NOTFOUND refusal maps to the not on this instance line rather than failing the whole estimate:

The doors fire before any engine is resolved, so a usage error is a usage error even on a box with no driver — and a flag that used to be accepted and silently inert now refuses with the one-flag fix in the hint. All five below run without touching an engine (each also prints the verb's usage, elided here):

(exit status 2 — BAD_OUT_DIAL; --pace without --out refuses the same way)

(exit status 2 — BAD_EXPLAIN)

(exit status 2 — BAD_FILES)

(exit status 2 — BAD_SCOPE; before the series this was an untyped RUNTIME at exit 1 with no hint)

(exit status 2 — BAD_MAX: the flag refusal wins even though the engine profile is also wrong; before the series this reported UNKNOWN_ENGINE)

The machine face of a door refusal — code, exit, message and hint, all typed, on stderr:

(exit status 2)

Engine refusals now signpost the next command (round 2 of the analysis, same day): a typed refusal with no engine hint gets the host's — verified live, never overwriting a hint the engine supplied:

(exit status 2 — re-executed at VSL*1.0*64: a deliberate refusal renders its reason alone at its classified exit; the trap's verb X faulted: prose now appears only on a GENUINE engine fault, at exit 1)

(exit status 2 — re-executed at VSL*1.0*64)

Also in the series, not transcribed here: --top 0 now lists everything on every verb that has it; rows/find --out gained --pace; find --raw --ids --out artifacts carry the reference map; a failed census size pass publishes the walk with measured.sizes naming the failure; and edit/reindex/policy refusals carry the instance declaration like every other verb's.
