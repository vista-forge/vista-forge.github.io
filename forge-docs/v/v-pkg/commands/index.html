Commands — v pkg

Inspect

Section titled “Inspect”

Examine a build without changing it.

Command What it does
v pkg parse Parse a .KID file and summarize its builds and sections.
v pkg classify Derive a .KID's reversibility class (pure-overwrite vs side-effecting) from its structure — no engine.
v pkg diff Compare a .KID to the live engine WITHOUT mutating it: per-artifact NEW/CHANGED/identical preview (read-only; exit 0).
v pkg lint Run the PIKS data-class gate over a .KID (exit 3 on a blocked file).
v pkg attest Validate the install-attestation audit ledger (hash chain + signatures; optional live replay).
v pkg attest verify Validate an attestation ledger's hash chain (+ signatures), optionally replaying it against the live engine.
v pkg attest check Check a .KID's pre-image sidecars against the ledger (and, with --engine, the live engine): the standing sidecar ↔ ledger ↔ engine consistency gate (C2/G-SIDECAR).

Transform

Section titled “Transform”

Decompose, assemble, and canonicalize builds.

Command What it does
v pkg decompose Split a .KID into a per-component KIDComponents/ tree.
v pkg assemble Reassemble a component tree back into a .KID.
v pkg roundtrip Verify decompose→assemble reproduces the build (exit 3 on drift).
v pkg merge Entry-level 3-way merge of ZWR files (git merge driver: base ours theirs; writes to ours, exit 3 on conflict).
v pkg canonicalize Substitute install-time IENs with "IEN" in a tree (LOSSY; review-only).

Build & install

Section titled “Build & install”

Build and install on a live engine.

Command What it does
v pkg build Build a KIDS transport global from a declarative build spec (deterministic, normalized export).
v pkg capture Capture a live compiled-FileMan component (input/print/sort template family) into a committed sidecar the build consumes (read-only).
v pkg install Install a built .KID on a live engine over the driver (preview by default; --commit runs the non-interactive KIDS load+install).
v pkg export Export an installed build off a live engine into a package source tree + rebuilt .KID (engine→git; read-only).
v pkg verify Verify a .KID's install on a live engine (#9.7 status + per-routine presence).

Back-out

Section titled “Back-out”

Snapshot and reverse an install.

Command What it does
v pkg snapshot Capture the live pre-image of a patch's routines into a restorable .KID (class-1 reversal).
v pkg restore Re-apply a pre-image snapshot .KID to revert routines to stock (preview by default; --commit installs).
v pkg uninstall Uninstall a .KID from a live engine (routine-only back-out: routines + #9.7/#9.6).
v pkg purge DESTROY a .KID's entire declared footprint to greenfield (routines incl. foreign, components, files, #9.7/#9.6/#9.4, sidecars). Preview by default; --commit to delete. The sanctioned clean after a leak/crash — NOT a reversal.
v pkg adopt Reconcile dangling crash intents: read the live engine, and when it PROVES a crashed op completed (or never landed), seal the missing ledger final. Preview by default (read-only probes); --commit to seal. Writes NO engine state — unprovable states route to purge/manual.

Global flags

Section titled “Global flags”

Every command accepts these.

Flag Type Default Env Description
-o, --output text | json | auto auto — Output format: text (TTY-styled), json, or auto.
--no-color bool — NO_COLOR Disable ANSI styling even on a TTY.
-v, --verbose bool — — Verbose diagnostics to stderr.
--version bool — — Print version and build info.

Exit codes

Section titled “Exit codes”
Code Meaning
0 ok
1 runtime error
2 usage error
3 check / gate failed
4 refused / substrate unavailable

Errors

Section titled “Errors”

Every typed refusal v pkg can raise, looked up by the code it printed: Errors.

Notes

Section titled “Notes”

Hand-written in the owning repository; the tables above are generated.

The facts the contract does not carry, in one place. Everything a single verb accepts, returns and refuses is on that verb's own page, generated from the contract.

What each exit class means here

Section titled “What each exit class means here”
Code Name When
0 OK success
1 Runtime engine / I/O / parse failure (INSTALL_FAILED, UNINSTALL_FAILED, …)
2 Usage bad flags (BAD_ANSWER, MULTI_BUILD_REGISTER, …)
3 Check drift / not-verified-clean / broken attestation (NOT_VERIFIED, VERIFY_CLEAN_FAILED, ATTEST_VERIFY_FAILED, ROUNDTRIP_FAILED)
4 Refused the safety stop — INSTALL_REFUSED (routine OR component clobber w/o pre-image), UNINSTALL_REFUSED (would brick a foreign routine / a ledger-overwritten component / side-effecting / wrong sidecar), AMBIGUOUS_COMPONENT (multiple same-named live records — never a guessed pre-image), ALREADY_INSTALLED, CHECKSUM_MISMATCH, SIDECAR_TAMPERED, NO_DRIVER

Exit 4 is the heart of the safety model: do not perform an irreversible engine mutation that cannot be honestly undone. Scripts and CI gate on it directly.

Environment and files

Section titled “Environment and files”

Environment (read by the driver, never on the command line):

  • YDB: M_YDB_BIN, M_YDB_CONTAINER, M_YDB_TRANSPORT, M_YDB_DIST, M_YDB_GBLDIR, M_YDB_ROUTINES
  • IRIS: M_IRIS_BASE_URL (full Atelier path ending …/api/atelier/v1/), M_IRIS_NAMESPACE, M_IRIS_USER, M_IRIS_PASSWORD
  • Attestation: VPKG_ATTEST_KEY (hex ed25519 seed, for --sign), VPKG_ATTEST_PUBKEY (hex public key, default for attest verify --trust)

Files v-pkg reads/writes alongside a .KID:

  • <kid>.preimage.kids — the auto-snapshot pre-image sidecar (install --auto-snapshot; auto-detected by uninstall)
  • <kid>.attest.jsonl — the attestation ledger (default; --attest <path> to relocate)

Key flags by verb (see v pkg <verb> --help for the full set):

Verb Notable flags
install --commit (a bare install previews), --snapshot <out>, --auto-snapshot, --allow-overwrite, --heal, --verify-checksums, --skip-env-check, --answer NAME=VALUE, --register-package "NAME", --attest <path>, --no-attest, --sign
uninstall --restore <preimage>, --backout <kid>, --force, --verify, --deregister, --attest <path>, --no-attest, --sign
restore --commit, --attest <path>, --no-attest, --sign
verify --drift
snapshot --name
diff (read-only; --engine/--transport only)
attest verify --trust <hexpub>, --replay, --engine, --transport
lint --piks <tsv>, --strict
build --src <dir>, --out <path>
capture --type "INPUT TEMPLATE", --name "<.01 NAME>", --file <n> (disambiguates same-named templates by their target FILE — compiled-template names are unique per file, not globally: A1B2 ENTRY names eight records on vehu), --out <sidecar.json>, --piks <tsv>, --strict
export --out-dir <tree> (the package source tree to write: kids/ + src/), --kid <path> (the rebuilt .KID; defaults to <out-dir>/dist/kids/<pkg>.kids), --piks <tsv>, --strict
