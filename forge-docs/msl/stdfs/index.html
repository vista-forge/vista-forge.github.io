do append^STDFS(path, data)

Section titled “do append^STDFS(path, data)”

Append data to path; create the file if missing.

Implementation: text-mode read-then-rewrite. For byte-faithful append at EOF use $$appendBytes^STDFS instead.

Parameters

  • path (path) — filesystem path; created if absent
  • data (string) — text content

Raises

  • U-STDFS-OPEN-FAIL — could not open for read or write

Example

See also $$writeFile^STDFS, do appendBytes^STDFS

Since v0.3.0.

do appendBytes^STDFS(path, data)

Section titled “do appendBytes^STDFS(path, data)”

Append data to path via O_APPEND — atomic at EOF, byte-faithful.

Parameters

  • path (path) — filesystem path; created if absent
  • data (byte-string) — one M character per byte

Raises

  • U-STDFS-NOT-WIRED — stdfs.so is unavailable
  • U-STDFS-OPEN-FAIL — open(2) failed

Example

See also do writeBytes^STDFS, do append^STDFS

Since v0.4.0.

Returns bool — 1 iff stdfs.so is loaded; 0 otherwise

$$dirname^STDFS(path)

Section titled “$$dirname^STDFS(path)”

Return the parent path (everything but the last component).

Trailing slashes are normalised first ("/foo/bar/" → "/foo").

Parameters

  • path (path) — POSIX path

Returns path — parent path; "." for no-slash input; "/" for root

Example

See also $$basename^STDFS, $$join^STDFS

Since v0.3.0.

$$exists^STDFS(path)

Section titled “$$exists^STDFS(path)”

Return 1 iff path exists; else 0.

Probes via $$openRead with timeout=0 — succeeds iff the path is openable. Avoids $ZSEARCH's per-process cache, so a path created and removed inside one M process round-trips correctly. Portable: openRead carries the engine branch and never throws.

Parameters

  • path (path) — filesystem path

Returns bool — 1 iff openable; 0 otherwise

Example

See also $$size^STDFS, $$readFile^STDFS

Since v0.3.0.

$$join^STDFS(left, right)

Section titled “$$join^STDFS(left, right)”

POSIX path join: absolute right replaces left.

Empty operand drops out. Trailing slash on left is collapsed.

Parameters

  • left (path) — left operand
  • right (path) — right operand (absolute right wins)

Returns path — joined path

Example

See also $$dirname^STDFS, $$basename^STDFS

Since v0.3.0.

$$openAppend^STDFS(path, timeout)

Section titled “$$openAppend^STDFS(path, timeout)”

Open path for append (create if missing); return $TEST.

Engine-portable: YDB (append) ↔ IRIS "WA". Never throws.

Parameters

  • path (path) — filesystem path; created if absent
  • timeout (int) — OPEN timeout in seconds (default 5)

Returns bool — 1 iff the device opened; 0 otherwise

Example

See also $$openWrite^STDFS, do append^STDFS

$$openRead^STDFS(path, timeout)

Section titled “$$openRead^STDFS(path, timeout)”

Open path read-only on the current engine; return $TEST.

Engine-portable: YDB (readonly) ↔ IRIS mode "R". Never throws — a missing/unopenable path returns 0. The caller uses + closes.

Parameters

  • path (path) — filesystem path to open for reading
  • timeout (int) — OPEN timeout in seconds (default 5; 0 = poll)

Returns bool — 1 iff the device opened; 0 on timeout/error

Example

See also $$openWrite^STDFS, $$openAppend^STDFS

Since v0.5.0.

$$openWrite^STDFS(path, timeout)

Section titled “$$openWrite^STDFS(path, timeout)”

Open path write-new (create/truncate); return $TEST.

Engine-portable: YDB (newversion:stream:nowrap) ↔ IRIS "WNS" (stream mode, no line wrap). Never throws.

Parameters

  • path (path) — filesystem path; truncated/created
  • timeout (int) — OPEN timeout in seconds (default 5)

Returns bool — 1 iff the device opened; 0 otherwise

Example

See also $$openRead^STDFS, $$openAppend^STDFS

Since v0.5.0.

$$readBytes^STDFS(path)

Section titled “$$readBytes^STDFS(path)”

Return file content as a byte string — no CR/LF normalisation.

For text I/O with newline-joining and CRLF normalisation, prefer $$readFile^STDFS instead.

Parameters

  • path (path) — filesystem path

Returns byte-string — file contents byte-for-byte

Raises

  • U-STDFS-NOT-WIRED — stdfs.so is unavailable
  • U-STDFS-OPEN-FAIL — open(2) failed
  • U-STDFS-READ-TRUNCATED — file exceeds the 1 MiB buffer cap (YDB max string length)

Example

See also $$readFile^STDFS, do writeBytes^STDFS

Since v0.4.0.

$$readFile^STDFS(path)

Section titled “$$readFile^STDFS(path)”

Return file content as a string (lines joined by $C(10)).

Trailing CR on each line is dropped (CRLF normalisation). A trailing LF is normalised away (round-trips with writeFile).

Parameters

  • path (path) — filesystem path

Returns string — file content; lines LF-separated, trailing LF dropped

Raises

  • U-STDFS-OPEN-FAIL — path is missing or unreadable

Example

See also $$writeFile^STDFS, $$readBytes^STDFS, do readLines^STDFS

Since v0.3.0.

$$size^STDFS(path)

Section titled “$$size^STDFS(path)”

Return size of path in bytes; -1 if missing or unreadable.

Implemented via a FIXED-mode OPEN/READ byte tally — does not depend on a stat callout, and is byte-exact in byte mode (ydb_chset=M), including unterminated final lines.

Parameters

  • path (path) — filesystem path

Returns int — byte count; -1 if missing or unreadable

Example

See also $$exists^STDFS, $$readBytes^STDFS

Since v0.3.0.

do writeBytes^STDFS(path, data)

Section titled “do writeBytes^STDFS(path, data)”

Write data to path verbatim — no trailing LF, no transcoding.

Parameters

  • path (path) — filesystem path; truncated if exists
  • data (byte-string) — one M character per byte (0..255)

Raises

  • U-STDFS-NOT-WIRED — stdfs.so is unavailable
  • U-STDFS-OPEN-FAIL — open(2) failed

Example

See also $$readBytes^STDFS, do appendBytes^STDFS, $$writeFile^STDFS

Since v0.4.0.

do writeFile^STDFS(path, data)

Section titled “do writeFile^STDFS(path, data)”

Write data to path (overwrite if exists).

Empty data creates a zero-byte file. Non-empty data ends in exactly one trailing LF on disk (YDB's SEQ stream-mode close finalises the last record; IRIS "WNS" does not, so the IRIS arm writes the terminator explicitly when data doesn't already end in LF) — so the on-disk byte count is engine-identical and readFile round-trips.

Parameters

  • path (path) — filesystem path; truncated if exists
  • data (string) — text content (lines may be LF-separated)

Raises

  • U-STDFS-OPEN-FAIL — could not open path for write

Example

See also $$readFile^STDFS, do writeBytes^STDFS, do writeLines^STDFS

Since v0.3.0.

do writeLines^STDFS(path, lines)

Section titled “do writeLines^STDFS(path, lines)”

Write lines(1..N) to path, separated and terminated by LF.

lines must be 1-indexed and dense (no gaps in $ORDER).

Parameters

  • path (path) — filesystem path; truncated if exists
  • lines (array) — by-ref local subscripted as lines(1..N)

Raises

  • U-STDFS-OPEN-FAIL — could not open path for write

Example

See also do readLines^STDFS, $$writeFile^STDFS

Since v0.3.0.
