In VS Code

Three extensions, one per question: how to write M, what a VistA system is, and what its documentation says. Each opens its chapter in the VSCode book.

M Language Tools for VS CodeThe M language in the editor, on any M engine.
  • Highlighting from the real parse treethe M grammar
  • Live diagnostics, format on savem lsp
  • Test Explorer, failures with valuesm test
  • Coverage in the gutterm coverage
  • Run a selection on the enginem engine

No parser and no engine access of its own: the editor shows what the command line would.

VistA CompassWhat a VistA system measurably is, beside your code.
  • Routine sidebar: callers, callees, globals, RPCs, options
  • Hover cards: the FileMan file behind a global, and whether it holds patient data
  • Go to definition, find references, RPC and option pickers
  • Package dashboard: size, couplings, kinds of data
  • Receipts: every fact cites the row it came from

Built on a measured model of a real VistA system: one verified download, then offline. No VistA instance needed.

VistA AtlasWhat the VA documentation says, inside VS Code.
  • A faceted library: domain, audience, document type, package
  • Ranked full-text search
  • A reading pane, section by section, every section citable
  • Deep links into a document or section, from Compass too

Built on the VA Software Document Library: one verified download, then offline.

Compass and Atlas are a pair: each links into the other.
