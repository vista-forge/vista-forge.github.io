$$census^VSLROW(file, bounds, token, out)

Section titled “$$census^VSLROW(file, bounds, token, out)”

The walked all-files catalog: count's fold over every ^DIC entry, one resumable page at a time (M8).

NEVER raises POLICY: a per-file read deny lands in that file's row as denied:true with the rung detail (the loud middle - one declaration must not blind the whole catalog, and a silent skip is the fail-open this plane forbids).

Parameters

  • file (numeric) — (optional) census exactly this ^DIC entry; 0/"" = every numeric first-level ^DIC subscript (the file-of-files, MD8-2)
  • bounds (array) — (by ref, optional) bounds("examined"/"elapsed"/"bytes") page budgets (defaults 300000 / 10000 ms / 786432 - the count-fold examined class)
  • token (string) — opaque continuation token from the prior page ("" = first page)
  • out (array) — (by ref) out(1..n)=<classified file-row JSON, walk order> - walkable {file,name,walked,hollow[,claimed]} | nodata | subfile | nestedroot | denied (header CENSUS section); out("completeness") with population "dic" (or "dic:<file>"), plus the __page convention

Returns numeric — the number of file rows emitted into this page

Raises

  • U-VSL-ROW-NOFILE — an explicit file scope names no ^DIC entry on this instance
  • U-VSL-ROW-TOKEN — malformed continuation token
  • U-VSL-ROW-STALE — the token's fingerprint does not match this request shape, or the in-flight file's DD changed mid-walk
  • U-VSL-ROW-BOUNDS — a bounds() value is not a legal budget (elapsed may be 0; bytes above the 786432 envelope ceiling refuses)
  • U-VSL-ROW-INSTANCE — the instance gate refused (class undeclared/unrecognized, real-data instance, or the Kernel PROD tripwire - VD-D26/D48)
  • U-VSL-ROW-AUDIT — the real-data read-audit write failed - the census refuses (fail-closed)

Since VSL1.037.

$$count^VSLROW(file, bounds, token, out, parent, filters, index, from, to, prefix)

Section titled “$$count^VSLROW(file, bounds, token, out, parent, filters, index, from, to, prefix)”

An honest record count: one bounded page of a resumable IEN-walk fold (or, parent-scoped, of ONE multiple instance's sub-IEN fold - A3).

Parameters

  • file (numeric) — FileMan file number (top-level; a SUB-file number is legal exactly when parent scopes it)
  • bounds (array) — (by ref, optional) bounds("examined"/"elapsed") page budgets (default 300000 / 10000 ms)
  • token (string) — opaque continuation token from the prior page ("" = first page)
  • out (array) — (by ref) out("walked")=candidates counted so far (cumulative), out("hollow")=those with no 0-node, out("claimed")=the header p4 count (reported, never trusted - VA-11; for a scoped count OMITTED when the node;0 header is absent), out("completeness")=<completeness JSON>, plus the __page convention
  • parent (string) — (optional) parent-record IENS scoping a SUB-file count (the subRows scope form)
  • filters (array) — (by ref, optional) the rows filter set (Q1.3): AND-conjoined predicates over the SAME closed table, so walked counts what PASSED and completeness carries filtered beside examined. Admitted on the file and index populations; a parent-scoped or depth fold refuses rather than ignore them
  • index (string) — (optional) count the entries of this NAMED INDEX instead of records (Q1.3, proposal 6.4): population index:&lt;name>, entries NEVER de-duplicated (a record with several in-range entries counts per entry), a dangling entry tallied in hollow, and claimed OMITTED - the header's p4 is a claim about records
  • from (string) — (optional, index only) inclusive lower key bound in STORED key space
  • to (string) — (optional, index only) inclusive upper key bound in stored key space
  • prefix (string) — (optional, index only) byte-prefix constraint; does not combine with from/to

Returns numeric — the cumulative walked count so far (final when more=0)

Raises

  • U-VSL-ROW-NOFILE — no such top-level file / no data root on this instance
  • U-VSL-ROW-SUBFILE — the number names a sub-file and no parent scope was given
  • U-VSL-ROW-PARENT — the parent scope is defective (the subRows door)
  • U-VSL-ROW-NOTFOUND — a parent-scope record does not exist
  • U-VSL-ROW-NESTEDROOT — the file is in the measured nested-root table (#1.1, #.6 - VD-D55): walked would count files, not records
  • U-VSL-ROW-TOKEN — malformed continuation token
  • U-VSL-ROW-STALE — the token's fingerprint does not match this request + DD state
  • U-VSL-ROW-BOUNDS — a bounds() value is not a legal budget (elapsed may be 0)
  • U-VSL-ROW-FILTER — a filter entry is malformed, its operator is outside the closed table, a value rode a bound clause, or filters were given for a population that cannot evaluate them (a scoped/depth fold)
  • U-VSL-ROW-FLTFIELD — a filter field is not admissible (computed / storage-less / a multiple outside bound / an extract location under bound)
  • U-VSL-ROW-NOINDEX — no such index on this file (index fold)
  • U-VSL-ROW-IXTYPE — the index is not a regular single-key whole-file index (index fold)
  • U-VSL-ROW-SEEK — prefix combined with from/to (index fold)
  • U-VSL-ROW-INSTANCE — the instance gate refused (class undeclared/unrecognized, real-data instance, or the Kernel PROD tripwire - VD-D26/D48)
  • U-VSL-ROW-POLICY — the declared per-file policy refused this read (VD-D25)
  • U-VSL-ROW-AUDIT — the real-data read-audit write failed - the read refuses (fail-closed)

Since VSL1.027.

$$del^VSLROW(file, iens, commit, out)

Section titled “$$del^VSLROW(file, iens, commit, out)”

Delete a record (or sub-record) - dry-run by DEFAULT (VD-D23).

Parameters

  • file (numeric) — FileMan file OR sub-file number
  • iens (string) — the record's concrete IENS
  • commit (numeric) — 0 (default) = dry-run: report what would go, touch nothing; 1 = actuate
  • out (array) — (by ref) dry-run: out("dryRun")=1 + out("report")=the record's raw row JSON; commit: out("deleted")=1

Returns numeric — 0 on a dry run, 1 on an actuated delete

Raises

  • U-VSL-ROW-NOFILE — no such file on this instance
  • U-VSL-ROW-IENS — malformed or placeholder IENS
  • U-VSL-ROW-NOTFOUND — no record at that IENS
  • U-VSL-ROW-DIERR — FileMan refused the deletion - its text rides $$lastError
  • U-VSL-ROW-LOCKTIMEOUT — the record is held by another writer past the bounded timeout - typed, retry-worthy, never a hang (PR-9)
  • U-VSL-ROW-INSTANCE — the instance gate refused (class undeclared/unrecognized, real-data instance, or the Kernel PROD tripwire - VD-D26/D48)
  • U-VSL-ROW-POLICY — the declared per-file policy refused this write (VD-D25 - writes are default-deny)

Since VSL1.033.

$$edit^VSLROW(file, iens, values, internal, out)

Section titled “$$edit^VSLROW(file, iens, values, internal, out)”

File values into an EXISTING record through FileMan's Filer.

Parameters

  • file (numeric) — FileMan file OR sub-file number
  • iens (string) — the record's concrete IENS (no placeholders - put creates)
  • values (array) — (by ref) values(field#)=value - EXTERNAL by default; "@" clears a field explicitly (refused on .01 - that is del's job; a required field's clear refuses through FileMan)

Returns numeric — 1 on success

  • U-VSL-ROW-NOTFOUND — no record at that IENS
  • U-VSL-ROW-VALUE — a value carries "^" or a control byte (both modes)
  • U-VSL-ROW-ARG — empty values / non-numeric field key / .01="@"
  • U-VSL-ROW-DIERR — FileMan refused - its text rides $$lastError; NOTHING filed (data + xrefs byte-identical, the VD-D41 shape)
  • U-VSL-ROW-LOCKTIMEOUT — the record is held by another writer past the bounded timeout - a typed, retry-worthy refusal, never a hang (PR-9; the RPC path has no run-lock)
  • U-VSL-ROW-INSTANCE — the instance gate refused (class undeclared/unrecognized, real-data instance, or the Kernel PROD tripwire - VD-D26/D48)
  • U-VSL-ROW-POLICY — the declared per-file policy refused this write (VD-D25 - writes are default-deny)

Since VSL1.033.

$$find^VSLROW(file, index, from, to, prefix, fields, tier, filters, bounds, max, token, out)

Section titled “$$find^VSLROW(file, index, from, to, prefix, fields, tier, filters, bounds, max, token, out)”

One bounded page of a named-index walk (the SECOND classified read, VD-D28).

emission floor: findRow rides the shared wEnc typed-encode outcome since *67; *76 lifts the sub-file door (VD-D125) - a sub-file page's rows additionally carry iens, and its completeness population reads "sub:<file>/index:<name>".

Parameters

  • file (numeric) — FileMan file number - top-level, or a non-WP SUB-file (VD-D125): a sub-file's regular LOCAL index walks file-wide through the depth odometer, every parent instance's index in path order, keys in stored order within each instance; rows then also carry the full iens, and completeness's population reads "sub:<file>/index:<name>"
  • index (string) — the index name (e.g. "B") - a regular single-key index, either style (whole-file at the top level, LOCAL on a sub-file); MUMPS/computed-style and compound indexes are refused
  • from (string) — (optional) inclusive lower key bound, in STORED key space - hands positioning to the index
  • to (string) — (optional) inclusive upper key bound, in stored key space (subscript collation)
  • prefix (string) — (optional) byte-prefix key constraint, in stored key space; does not combine with from/to
  • fields (string) — projection: ";"-separated field numbers, or "*" (all top-level; the default); ignored for tier "raw"
  • tier (string) — "external" (default) | "internal" | "raw" (VD-D30)
  • filters (array) — (by ref, optional) filters(n)="<field>|<op>|<value>" AND-conjoined stored-field predicates on the CANDIDATE RECORD (a dangling entry evaluates as all-empty); ops = '= > < >= <= contains starts (closed table); evaluated on the INTERNAL value per candidate
  • bounds (array) — (by ref, optional) bounds("bytes"/"examined"/"elapsed") page budgets; see header for defaults/derivations (bytes may only be LOWERED from 786432)
  • max (numeric) — rows budget (page size; default 4000 - see header)
  • token (string) — opaque continuation token from the prior page ("" = first page)
  • out (array) — (by ref) out(<emission ordinal>)=<row JSON incl. key+ien> - NEVER keyed by IEN (an index walk emits duplicates); out("completeness"), plus the __page convention

Returns numeric — the number of rows emitted into this page

Raises

  • U-VSL-ROW-NOFILE — no such top-level file / no data root on this instance
  • U-VSL-ROW-SUBFILE — the sub-file's UP chain exceeds 20 levels or cycles - the walk refuses rather than spin
  • U-VSL-ROW-WFIELD — the file is a word-processing sub-file - its records are lines; textGet reads them (VD-D24)
  • U-VSL-ROW-NESTEDROOT — the file is in the measured nested-root table (#1.1, #.6 - VD-D55)
  • U-VSL-ROW-NOINDEX — the file has no index of that name (either style)
  • U-VSL-ROW-IXTYPE — the classifier ($$name^VSLDDK - the ONE admit table, VD-D50) marks the name unwalkable: mumps/trigger/dangling/compound/record-level/computed-key/foreign-root - site-authored index logic is never evaluated
  • U-VSL-ROW-SEEK — prefix combined with from/to (one seek shape per walk)
  • U-VSL-ROW-BADFIELD — a projected or filtered field is not in the file's DD
  • U-VSL-ROW-RAWFIELDS — a fields spec was passed under tier raw (raw returns data nodes)
  • U-VSL-ROW-DEPTH — a "**" field spec (sub-file depth) was requested
  • U-VSL-ROW-TIER — unknown projection tier
  • U-VSL-ROW-PROJFAULT — the retriever hard-faulted mid-projection - typed, never a bare M fault (D6)
  • U-VSL-ROW-FILTER — a filter entry is malformed or its operator is outside the closed table
  • U-VSL-ROW-FLTFIELD — a filter field is not a stored top-level field (computed / multiple / word-processing / storage-less)
  • U-VSL-ROW-TOKEN — malformed continuation token
  • U-VSL-ROW-STALE — the token's fingerprint does not match this request shape + seeks + filters + DD + index definition
  • U-VSL-ROW-BOUNDS — a bounds() value is not a legal budget (elapsed may be 0; bytes above the 786432 envelope ceiling refuses)
  • U-VSL-ROW-DIERR — FileMan's retriever filed a DIERR (detail in $$lastError)
  • U-VSL-ROW-INSTANCE — the instance gate refused (class undeclared/unrecognized, real-data instance, or the Kernel PROD tripwire - VD-D26/D48)
  • U-VSL-ROW-POLICY — the declared per-file policy refused this read (VD-D25)
  • U-VSL-ROW-AUDIT — the real-data read-audit write failed - the read refuses (fail-closed)

Since VSL1.029.

$$fldProf^VSLROW(file, bounds, token, out, parent)

Section titled “$$fldProf^VSLROW(file, bounds, token, out, parent)”

The FIELDS profile: ONE walk, a per-field bound tally off the DD's own node/piece map (Q1.5, proposal 6.11).

Parameters

  • file (numeric) — FileMan file number - top-level, or a SUB-file (scoped to one instance by parent, else walked file-wide at depth)

  • iens (string) — the record's concrete IENS (text files into EXISTING records; put creates them)
  • field (numeric) — the word-processing field number
  • mode (string) — "replace" (default "": the whole field is erased first - WP^DIE's no-flag shape) | "append" (flag A) | "clear" (wp_root "@"; takes NO lines)
  • lines (array) — (by ref) lines(n)=BASE64 of line n's bytes - the text plane's PINNED wire form (see header TEXT section); keys are positive canonic numbers, renumbered contiguously on filing; "^" is EXEMPT in the DECODED line (VD-D20 as ruled - WP lines store WHOLE; 196 of 45,295 measured), control bytes refuse; a blank line ("") is legal content
  • out (array) — (by ref) out("mode")=the resolved mode; out("lines")=lines filed (0 for clear)

Returns numeric — 1 on success

Raises

  • U-VSL-ROW-NOFILE — no such file on this instance
  • U-VSL-ROW-BADFIELD — the file has no such field
  • U-VSL-ROW-WFIELD — the field is not word-processing (scalar/computed: put/edit file those; a multiple: write its sub-file via IENS) or the file IS a WP sub-file (target the parent field)
  • U-VSL-ROW-IENS — malformed or placeholder IENS (text files into existing records)
  • U-VSL-ROW-NOTFOUND — no record at that IENS
  • U-VSL-ROW-ARG — bad mode / empty lines outside clear / lines under clear / a non-numeric lines key / a lines value that is not base64
  • U-VSL-ROW-VALUE — a decoded line carries a control byte (VD-D20 - the WP exemption covers the ^ delimiter alone)
  • U-VSL-ROW-DIERR — WP^DIE refused - FileMan's own text rides $$lastError (VD-D19); the field is byte-unchanged (TROLLBACK)
  • U-VSL-ROW-INSTANCE — the instance gate refused (class undeclared/unrecognized, real-data instance, or the Kernel PROD tripwire - VD-D26/D48)
  • U-VSL-ROW-POLICY — the declared per-file policy refused this write (VD-D25 - writes are default-deny)

$$textGet^VSLROW(file, iens, field, bounds, token, out)

Section titled “$$textGet^VSLROW(file, iens, field, bounds, token, out)”

One bounded page of a word-processing field's lines - the paged, faithful WP read.

WHY A VERB and not a documented get tier-path: rows/get emit a WP field as a line array INSIDE one row JSON - unpaged, so a field whose encoded content exceeds the 786432 envelope budget is structurally UNREADABLE there (the envelope rides as ONE M string); and get() serves top-level files only, while a WP field can live on a sub-record that only an IENS can address. textGet is the paged, iens-addressable read; small fields keep reading fine through get/rows (both unchanged).

Parameters

  • file (numeric) — FileMan file OR sub-file number holding the WP field
  • iens (string) — the record's concrete IENS
  • field (numeric) — the word-processing field number
  • bounds (array) — (by ref, optional) bounds("bytes") page budget - default AND maximum 786432 (the envelope ceiling); the ONLY budget textGet takes: one retriever call per page and no site M leaves nothing for examined/elapsed to meter
  • token (string) — opaque continuation token from the prior page ("" = first page)
  • out (array) — (by ref) out(1..k)=one JSON VALUE per line - a JSON string (clean), {"b64":"..."} (a unit >= 0x80 rides base64 over its UTF-8 bytes losslessly - the M1 value contract), or {"error":{...}} (a line whose encoding ALONE exceeds the budget emits typed and the cursor advances - the progress guarantee); out("total")=the field's full line count this retrieval; out("completeness")=<completeness JSON> (D2/VD-D52); plus the __page convention

Returns numeric — lines emitted into this page

Raises

  • U-VSL-ROW-NOFILE — no such file on this instance
  • U-VSL-ROW-BADFIELD — the file has no such field
  • U-VSL-ROW-WFIELD — the field is not word-processing, or the file IS a WP sub-file (target the parent field)
  • U-VSL-ROW-IENS — malformed or placeholder IENS
  • U-VSL-ROW-NOTFOUND — no record at that IENS
  • U-VSL-ROW-TOKEN — malformed continuation token
  • U-VSL-ROW-STALE — the token's fingerprint does not match this request shape + the field's DD state
  • U-VSL-ROW-BOUNDS — a bounds() key other than "bytes", an illegal value, or a budget above the 786432 ceiling
  • U-VSL-ROW-DIERR — FileMan's retriever filed a DIERR (detail in $$lastError)
  • U-VSL-ROW-INSTANCE — the instance gate refused (class undeclared/unrecognized, real-data instance, or the Kernel PROD tripwire - VD-D26/D48)
  • U-VSL-ROW-POLICY — the declared per-file policy refused this read (VD-D25)
  • U-VSL-ROW-AUDIT — the real-data read-audit write failed - the read refuses (fail-closed)

Since VSL1.034.
