$$ddcensus^VSLINTEG(to, out)

Section titled “$$ddcensus^VSLINTEG(to, out)”

The DD-side denominators: field census by t/s/o, xref definitions, the IX and KEY registers, and the ^DIC catalog states.

Parameters

  • to (numeric) — bound the ^DD field-census walk to file numbers <= to (0/"" = the whole dictionary); the IX/KEY/catalog censuses are whole-instance regardless (the oracle's own bound semantics)
  • out (array) — (by ref) out("dd:<t|s|o>:<kind>")={n} — field definitions by owner class (t = top-level, s = sub-file, o = orphan DD) and kind (c computed, z semicolon-less, m multiple, e extract, p pointer, v variable pointer, s set, d date, n number, f free text, t total, x xref definitions); out("ix")={n} the new-style index register count; out("dic")={files,nodd,nogl,noglobal} the catalog census (entries, no ^DD, no GL root, GL root whose data global does not exist); out("key:<file>")={keys} the KEY register census per keyed file and out("keytot")={files,keys} — the CENSUS only: the check VD-D105 reserved is the keys sweep (VD-D111), and the two register totals must agree (the intra-instrument cross-check).

Returns numeric — the number of out() rows emitted

Raises

  • U-VSL-INTEG-INSTANCE — the instance gate refused (VD-D26/D48)
  • U-VSL-INTEG-AUDIT — the real-data read-audit write failed (fail-closed)

Since VSL1.073.

$$descent^VSLINTEG(to, out)

Section titled “$$descent^VSLINTEG(to, out)”

Sweep the sub-file planes (VD-D112): every admitted multiple descended depth-first to the declared bound, the pointer/type predicates restated one level down.

emission floor: *76 emits the walked zero (VD-D115) - a visited-empty non-WP multiple's recs=0 row joins the set; pre-*76 the row was silently absent. Existing rows are byte-identical (VD-D112); totals rows counts the added zeros.

Parameters

  • to (numeric) — bound the ^DIC walk to top-level file numbers <= to (0/"" = the whole instance); descent below an admitted file is always full-depth
  • out (array) — (by ref) out("<top-level file#>/<sub-file#>")={depth,recs,pv, pdang,pdfold,pfree,pffold,pres,prfold,vv,vdang,vdfold,vmal,vmfold,sv,sbad,sbfold,sdrift, scfold,dv,dbad,dbfold,nv,nbad,nbfold,hollow,hchild,hofold} per (file, sub-file) pair with any walked sub-record - the sub-census denominators (depth = the sub-file's UP-chain length; recs; per-kind value counts) plus the nine *-sub finding classes with their D110 membership folds (same predicates as the top-level sweeps, same fold recipes, the stored value in walk order), and the hollow counts: hofold folds the record-base spelling (root + subscript path + trailing comma) at walk level >= 2 ONLY - depth-1 hollow sub-records stay the hollowsub sweep's class (VD-D112: existing rows byte-identical). A row with zero findings still emits - an absent row is not a zero. A declared non-WP multiple the walk VISITS and finds empty emits its recs=0 row (VD-D115: the walked zero is a fact); a multiple below an empty ancestor is never visited - its zero is derived offline, and an empty WP multiple stays a declared exclusion. Traversal contract (the oracle's): records ascending, a sub-record's values in ITS OWN field-table order BEFORE descending, multiples in field-table order, depth-first. Admission travels verbatim: audit-class files never enter the walk (silently, as the oracle's s sweep - the six census sweeps carry the loud x-rows and the layout contract-verify), WP sub-files are excluded, values are read only at a real node;piece location, and a sub-file's fields come from ITS OWN dictionary. Plus policy d-rows and out("totals")= {files,toprecs,subrecs,rows,pv,pdang,pfree,pres,vv,vdang,vmal,sv,sbad,sdrift,dv,dbad, nv,nbad,hollow,hchild,beyondmax,descentmax,hol1..hol6} - the DECLARED bound (6), the beyond-bound sub-records counted by name (never silently dropped), and per-walk-level hollow counts.

Returns numeric — the number of per-(file, sub-file) rows emitted

Raises

  • U-VSL-INTEG-INSTANCE — the instance gate refused (VD-D26/D48)
  • U-VSL-INTEG-AUDIT — the real-data read-audit write failed (fail-closed)

Since VSL1.075.

$$headers^VSLINTEG(to, out)

Section titled “$$headers^VSLINTEG(to, out)”

Sweep the header ledger: every file's 0-node claim vs the walked truth, plus hollow records.

emission floor: max became a byte-exact STRING at *74 (the foia #.44 decimal-IEN two-instrument finding).

Parameters

  • to (numeric) — bound the ^DIC walk to file numbers <= to (0/"" = the whole instance)
  • out (array) — (by ref) out(<file#>)={claim,walk,last,max,hollow,hchild,hfold} per file with a GL root: claim/last are the 0-node's count (p4) and last-IEN (p3) pieces RAW (strings; "" = no claim, distinct from 0), walk the walked record count, max the walked max IEN as a STRING in its M-canonic subscript spelling (an IEN is an identity, not a quantity: JSON number normalization would respell the decimal IEN .999 as 0.999 - measured on foia #.44 - and break the oracle contract's byte identity), hollow/hchild the records with no 0-node value and those of them carrying child nodes (VA-6), hfold the D110 fold over the hollow IEN membership in walk order. Plus the admission x-rows, policy d-rows, and out("totals")={files,nogl} (files-with-GL / files-without denominators) — the module-header emission contract.

Returns numeric — the number of per-file ledger rows emitted

Raises

  • U-VSL-INTEG-INSTANCE — the instance gate refused (class undeclared/unrecognized, or the Kernel PROD tripwire - VD-D26/D48)
  • U-VSL-INTEG-AUDIT — the real-data read-audit write failed - the sweep refuses (fail-closed)
  • U-VSL-INTEG-ADMIT — an audit-class file's first-level subtree headers no longer claim its number - the pinned A4/D108 layout changed; re-derive the admission rule

Since VSL1.073.

$$hollowsub^VSLINTEG(to, out)

Section titled “$$hollowsub^VSLINTEG(to, out)”

Sweep depth-1 sub-records of every multiple field (WP excluded): hollow and hollow-with-children (A1/D105).

Parameters

  • out (array) — (by ref) out(<file#>)={fields,walked,hollow,hchild,hfold} per file with any hollow sub-record: fields = multiple fields admitted (subfile-typed, node;0 location, word-processing subfiles excluded), walked = depth-1 sub-records walked, hollow/ hchild = those with no 0-node value and those of them carrying child nodes, hfold the D110 fold over the "<ien>^<node>^<sub-ien>" membership in walk order. Depth 1 only — deeper descent stays a sized decision for the build (D105). Plus x-rows, d-rows, and out("totals")={mfields,walked,hollow,hchild} — the sweep denominators.

  • U-VSL-INTEG-AUDIT — the real-data read-audit write failed (fail-closed)
  • U-VSL-INTEG-ADMIT — the pinned A4/D108 audit-class layout changed

$$indexb^VSLINTEG(naive, pop, to, out)

Section titled “$$indexb^VSLINTEG(naive, pop, to, out)”

The parameterized index read (D107): both directions of the B-subtree audit over a population the CALLER supplies.

emission floor: explicit rows gained the directions echo and the entries-only leg shape at *75 (the population row grammar widened to five fields in the same build); naive rows are byte-identical.

Parameters

  • naive (numeric) — 1 = the engine expands the NAIVE population itself: every admitted file with a stored "B" subtree, terminal-depth-2 IEN, full/30/63 truncation. This is the oracle-VERIFICATION instance — the measured cost of naivety (proposal section 3.5), never the product feed: storage-driven inference stays forbidden in anything the host ships (D107), so the host's population arrives through pop() instead.
  • pop (array) — (by ref) explicit population rows, pop(1..n) each "<file>|<base64 subtree>|<ien rule>|<truncations>|<directions>": file = a top-level catalog file with a GL root (audit-class files refuse — A4/D108 admission is not overridable); subtree = the stored index subtree name, base64 (a name is DD text and may carry the delimiter); ien rule = a closed vocabulary, today exactly "terminal2" (the entry's IEN is the depth-2 subscript when numeric); truncations = comma-joined key lengths to probe on the record->entry direction, 0 = full length (the naive instance is "0,30,63") — REQUIRED non-empty on a both row, REQUIRED EMPTY on an entries row (it parameterizes the leg that then does not run); directions = "both" | "entries" (VD-D113), REQUIRED with no default — a 4-field row refuses, because a host and an engine that disagree about which legs ran must fail loud. Duplicate (file, subtree) rows refuse — one population, one visit.
  • to (numeric) — bound the naive ^DIC walk to file numbers <= to (0/"" = whole instance); does not combine with an explicit population — the feed IS the scope
  • out (array) — (by ref) naive: out(<file#>)={entries,dangling,dgfold,records, missing,msfold,long} per file with a stored B carrying any entry or named record, plus x-rows/d-rows and out("totals")={files,entries,dangling,records,missing,long}. Explicit: out(<row ordinal>)= the facts of the legs the row DECLARED plus {file,sub,stored, directions}: a both row carries every key; an entries row carries entries/dangling/ dgfold ONLY — the record->entry keys are ABSENT, unreadable rather than zero, so no consumer can read the leg that did not run (VD-D113/D107). stored=0 means the named subtree holds nothing on this instance and no leg ran — a named non-fact, not a zero. out("totals")={rows}. entries/dangling = every (key, terminal) pair and those whose numeric IEN names no record; records/missing = records with a .01 (0-node piece 1) and those with no entry at ANY probed truncation; long = .01 values past the 180-byte probe guard, counted apart (subscript-length safety); folds over both finding memberships (D110).

Returns numeric — the number of per-file (naive) or per-row (explicit) rows emitted

Raises

  • U-VSL-INTEG-ARG — no population, both populations, an explicit population with a to bound, or a malformed/out-of-vocabulary/duplicate/inadmissible population row — including a 4-field row (directions is required, VD-D113) and a truncation list on an entries-only row
  • U-VSL-INTEG-INSTANCE — the instance gate refused (VD-D26/D48)
  • U-VSL-INTEG-AUDIT — the real-data read-audit write failed (fail-closed)
  • U-VSL-INTEG-ADMIT — the pinned A4/D108 audit-class layout changed

Since VSL1.073.

$$keys^VSLINTEG(to, out)

Section titled “$$keys^VSLINTEG(to, out)”

Sweep the KEY register (VD-D111): decode every registered key, then CHECK every measurable one - top-level and depth-1 sub-file scope - over the DECLARED-shape tuple.

Parameters

  • to (numeric) — bound the CHECK passes to keyed-file numbers <= to (0/"" = the whole instance); the register decode (pass A) is whole-register regardless - coverage counts are a property of the register, not of a bound
  • out (array) — (by ref) out("k:<file>/<name>")={ki,pri,ui,nfld,sub,rt,ixkind,ml, disp} per REGISTERED key - the pass-A decode: register IEN, priority, uniqueness-index IEN, field count, sub-file flag, the index's declared ROOT TYPE and TYPE, how many positions declare a MAXIMUM LENGTH, and the disposition (measurable | subfile-measurable | unmeasurable:<reason> | excluded:audit-class). Nothing is inferred from storage. out("<file>/<name>")= the CHECK row per measurable key: {recs,nulln, nufold,dupn,tuples,dufold,longn,maxtuple,ixkind} - records walked, key-null-field count
  • fold (over "<ien>" / "<ien>^<subien>" membership), key-duplicate count (records beyond the first sharing a tuple; null-tuple records EXCLUDED - folding them manufactures the finding) + distinct colliding tuples + fold (over "<tuple>^<ien>" / "<tuple>^<ien>^ <subien>"), tuples past the 400-byte guard counted by name (never subscripted), and the longest tuple seen. The checked tuple is the DECLARED-shape tuple: SEQUENCE order, each position truncated to its uniqueness-index subscript's declared MAXIMUM LENGTH, length-prefixed. A sub-file key's row adds {parents,scope,parent} - scope is the uniqueness index's declared ROOT TYPE (W = whole sub-file, I = per parent record), READ, never inferred; a keyed sub-file its parent declares no multiple field for emits the named non-fact {parent,reason:"no-multiple-field"} instead. Plus out("disp:<disposition>") ={n} coverage counts, policy d-rows on the checked files' data (register rows are DD metadata and always emit), and out("totals")={registered,tkeys,trecs,tnull,tdup,tlong, skeys,srecs,snull,sdup}.

Returns numeric — the number of check rows emitted (top + sub + not-walked)

Raises

  • U-VSL-INTEG-INSTANCE — the instance gate refused (VD-D26/D48)
  • U-VSL-INTEG-AUDIT — the real-data read-audit write failed (fail-closed)
  • U-VSL-INTEG-KEY — two register keys share (file, name) - the emission identity would collide; fail closed, never a silent overwrite

Since VSL1.075.

$$pointers^VSLINTEG(to, out)

Section titled “$$pointers^VSLINTEG(to, out)”

Sweep the pointer plane: every stored plain/variable pointer value resolved against its target root.

emission floor: the per-(target root, source file) pair rows (VD-D114) joined at *75; the per-file rows are byte-identical.

Parameters

  • to (numeric) — bound the ^DIC walk to file numbers <= to (0/"" = the whole instance)
  • out (array) — (by ref) out(<file#>)={fields,vals,dang,dfold,ft,ffold,res,rfold, vvals,vdang,vdfold,vmal,vmfold} per file with any stored pointer value: fields = piece- addressable pointer fields (plain + variable), vals/dang plain values stored and dangling, ft/res the A5/D109 malformed split (freetext = does not resolve at +V; res = +V>0 names a real record an exact-match consumer misses), vvals/vdang/vmal the variable-pointer values, dangling, and malformed (no root or non-numeric IEN half); each finding class carries its D110 membership fold. Plus out("p:<file#>/<target root>")={n} per (target root, source file) pair carrying DANGLING mass (VD-D114): no threshold, no cap, counts only - membership churn rides the source file's dangling folds, which cover the identical membership. The target is the ROOT as the dictionary spells it (plain) or as the value names it (vptr), byte-exact - root->file mapping is the host's interpretation. Plus x-rows, d-rows, and out("totals") with the per-file count keys minus the folds — the sweep denominators.

Returns numeric — the number of per-file rows emitted

Raises

  • U-VSL-INTEG-INSTANCE — the instance gate refused (VD-D26/D48)
  • U-VSL-INTEG-AUDIT — the real-data read-audit write failed (fail-closed)
  • U-VSL-INTEG-ADMIT — the pinned A4/D108 audit-class layout changed

Since VSL1.073.

$$types^VSLINTEG(to, out)

Section titled “$$types^VSLINTEG(to, out)”

Sweep declared-type conformance: set membership, FM internal-date shape, numeric canon - grammar ONLY (D108).

Parameters

  • to (numeric) — bound the ^DIC walk to file numbers <= to (0/"" = the whole instance)
  • out (array) — (by ref) out(<file#>)={set,snotable,sdrift,snfold,sdfold,dates, dbad,dfold,nums,nbad,nfold} per file with any stored set/date/number value: set values checked against the field's OWN code table with case-drift (case-folds to a member) its own counted sub-class (A4/D108), dates against the FM internal shape (7N or 7N.1N with month <= 12, day <= 31), numbers against canon (V=+V); folds over each violation membership. Input transforms are NEVER executed (D108: #712.5's 8,239 shipped counterexamples). Plus x-rows, d-rows, and out("totals") with the count keys — the sweep denominators.

Returns numeric — the number of per-file rows emitted
