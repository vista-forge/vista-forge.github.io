How it works

One index, two front doors

People and AI assistants read the same index, the same way: the same search rules, the same everyday names for packages, the same sections under the same ids.

You, in a browser
The web app
  • the Library and the Inventory, side by side
  • facets to narrow, suggestions as you type
  • a reading pane with figures and tables, and find within a manual

Served on this site.

Your AI assistant
The MCP server
orientationsearchreadlookupquery
  • five read-only tools, over the Model Context Protocol
  • every answer cites the section it came from

Runs beside a copy of the index; not served from this site.

↓↓
One search the same rules at every front door

Keywords

Every keyword must appear; "quotes" for an exact phrase; OR between alternatives; NOT to exclude a word. One set of 32 test cases that every front door passes.

Everyday names

One table of plain-English names, read by every front door: blood bank finds the Laboratory package and VBECS, email finds MailMan.
