Note

Generated, not written — v-pkg derives this from its own committed contract, doc plane and typed-refusal index, and reds if the copy in docs/guides/v-pkg-reference.md has fallen behind them. It carries no narrative for the same reason it cannot go stale.

This page is generated from this repository’s own committed artifacts — the command contract, the doc plane, and the typed-refusal index — each of which has a golden test in this repo’s make check, so none of them can describe a surface the tool does not have. install

Section titled “install”

Install a built .KID on a live engine over the driver (preview by default; –commit runs the non-interactive KIDS load+install).

engine access write · mutates data · reversibility reversible.

Argument Type Required Description
kid-file string yes Path to the built .KID transport file to install on the live engine.
Flag Type Default Description
--engine (required) ydb | iris — Engine to reach: ydb or iris.
--transport local | docker | remote — Driver transport: local | docker | remote. REQUIRED — v-pkg seals it into the signed attestation, so it is never defaulted or inferred.
--lock-wait duration 10m Bounded wait for the per-engine run bracket (v pkg is a batch consumer — decision #3). The wait names the holder it is waiting on; it is never silent. 0 = refuse immediately if the engine is busy.
--attest string — Append the audit record to this ledger path (default: .attest.jsonl next to the .KID).
--no-attest bool — Do NOT write an attestation audit record for this op (default: record every engine-mutating op).
--sign bool — Sign each record with a detached ed25519 signature (key from $VPKG_ATTEST_KEY, a hex 32-byte seed) — tamper-RESISTANT, not just tamper-evident.
--commit bool — Actuate the install. WITHOUT this flag, install PREVIEWS against the live engine (read-only, exit 0): NEW/CHANGED/identical per routine and would-add/would-change/identical per component — the same plan as ‘v pkg diff’. Nothing on the engine changes until –commit.
--snapshot string — Capture the pre-image of any routine this install overwrites to this .KID before installing (enables uninstall –restore).
--auto-snapshot bool — Like –snapshot, but to the conventional sidecar path (.preimage.kids) that uninstall auto-detects.
--allow-overwrite bool — Overwrite existing routines WITHOUT capturing a pre-image (unsafe: uninstall cannot then restore them).
--heal bool — Before installing, purge a corrupt half-install (a #9.7 entry with no usable 0-node that falsely blocks reinstall as ‘already-installed’); never touches a healthy install.
--verify-checksums bool — Make the transport-checksum check a HARD gate: REFUSE a .KID whose stored routine checksum does not match its shipped source (default: warn and proceed — ~6% of real foreign patches carry a self-inconsistent checksum, indistinguishable from tampering offline).
--skip-env-check bool — Skip the build’s environment-check routine + Required-Build (#9.611) enforcement before filing (default: run them, KIDS-faithful).
--answer list — Pre-answer a build install question as NAME=VALUE (the internal answer $ANSWER^XPDIQ returns); repeatable.
--register-package string — Record the PACKAGE #9.4 footprint under this long NAME (find-or-create by the install-name prefix; stamps VERSION + PATCH APPLICATION HISTORY so $VER/$PATCH^XPDUTL see the install).

Typed refusals: BAD_ANSWER · MULTI_BUILD_REGISTER · MULTI_BUILD_SNAPSHOT · NO_BUILD · READ_FAILED.

engine access read.

Argument Type Required Description

adopt

Section titled “adopt”

Reconcile dangling crash intents: read the live engine, and when it PROVES a crashed op completed (or never landed), seal the missing ledger final. Preview by default (read-only probes); –commit to seal. Writes NO engine state — unprovable states route to purge/manual.

engine access read.

Argument Type Required Description
kid-file string yes The .KID whose attestation ledger to reconcile — every dangling intent for the connected engine is graded against the live engine.
Flag Type Default Description
--engine (required) ydb | iris — Engine to reach: ydb or iris.
--transport local | docker | remote — Driver transport: local | docker | remote. REQUIRED — v-pkg seals it into the signed attestation, so it is never defaulted or inferred.
--lock-wait duration 10m Bounded wait for the per-engine run bracket (v pkg is a batch consumer — decision #3). The wait names the holder it is waiting on; it is never silent. 0 = refuse immediately if the engine is busy.
--commit bool — Seal the closing finals for provable verdicts (adopt-complete / not-completed). Default off = preview: the same read-only engine probes, verdicts printed, nothing written.
--attest string — Reconcile this ledger path (default: .attest.jsonl next to the .KID).
--sign bool — Sign each closing final with a detached ed25519 signature (key from $VPKG_ATTEST_KEY) — required to keep a –sign ledger verifiable with –trust.

attest verify

Section titled “attest verify”

Validate an attestation ledger’s hash chain (+ signatures), optionally replaying it against the live engine.

engine access read.

Argument Type Required Description
ledger string yes Path to the attestation ledger (JSON Lines) to validate.
Flag Type Default Description
--trust string — Pin every record’s signature to this hex ed25519 public key (default $VPKG_ATTEST_PUBKEY). Fails if any record is unsigned or signed by a different key.
--replay bool — Also read each recorded routine off the live engine and confirm it still matches the record’s AFTER checksum (needs –engine).
--engine ydb | iris — Engine for –replay: ydb or iris.
--transport local | docker | remote — Driver transport for –replay. REQUIRED for the live tier — never defaulted (see engineConn.client).
--lock-wait duration 10m Bounded wait for the per-engine run bracket during –replay (decision #3; batch default).

Typed refusals: ATTEST_VERIFY_FAILED · BAD_TRUST_KEY · LEDGER_UNREADABLE · REPLAY_INSTANCE_ABSENT · REPLAY_NO_ENGINE · REPLAY_READ_FAILED.

attest check

Section titled “attest check”

Check a .KID’s pre-image sidecars against the ledger (and, with –engine, the live engine): the standing sidecar ↔ ledger ↔ engine consistency gate (C2/G-SIDECAR).

engine access read.

Argument Type Required Description
kid-file string yes Path to the .KID whose pre-image sidecars to check against the ledger (and, with –engine, the live engine).
Flag Type Default Description
--attest string — Ledger path to check against (default: .attest.jsonl next to the .KID).
--engine ydb | iris — Also check the ledger’s latest state against the live engine: ydb or iris (live tier).
--transport local | docker | remote — Driver transport for the live tier. REQUIRED — never defaulted (see engineConn.client).
--lock-wait duration 10m Bounded wait for the per-engine run bracket during the live tier.

Typed refusals: LIVE_CHECK_FAILED · READ_FAILED.
