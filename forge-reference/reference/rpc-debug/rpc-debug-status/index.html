Section titled “Flags”
Flag Type Default Env Description
--engine ydb | iris ydb VRPC_ENGINE Engine to reach: ydb or iris ($VRPC_ENGINE).
--transport local | docker | remote docker VRPC_TRANSPORT Driver transport: local | docker | remote ($VRPC_TRANSPORT).
--container NAME string — VRPC_CONTAINER Engine container/instance name; sets M__CONTAINER ($VRPC_CONTAINER).
--lock-wait duration 30s — How long to wait for the engine run-lock before refusing (0 = skip immediately when busy).
