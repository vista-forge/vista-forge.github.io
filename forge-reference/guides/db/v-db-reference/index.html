Note

Generated, not written — v-db derives this from its own committed contract, doc plane and typed-refusal index, and reds if the copy in docs/guides/v-db-reference.md has fallen behind them. It carries no narrative for the same reason it cannot go stale.

This page is generated from this repository’s own committed artifacts — the command contract, the doc plane, and the typed-refusal index — each of which has a golden test in this repo’s make check, so none of them can describe a surface the tool does not have. Regenerate with make reference; a stale copy reds the gate rather than shipping.

It deliberately carries no narrative. When to reach for a verb, how the workflows fit together and why the safety model is what it is are the user guide’s job, because a generator writing those would be inventing them.

Analyze

Section titled “Analyze”

Sizing the database as it is — measured counts and sampled record sizes.

estimate

Section titled “estimate”

Estimate export size for a set of files (record count × sampled record size) and fit it against a cap (exit 3 over cap).

engine access read.

Flag Type Default Description
--engine string vehu VistA engine profile to reach (vehu = YDB, foia = IRIS).
--lock-wait duration 30s How long to wait for the engine run-lock before refusing (0 = skip immediately when busy).
--timeout duration — Host wall-clock bound on ONE engine visit; a hung page is aborted engine-side, not just abandoned. Unset = the verb’s derived default (180s; a whole-instance sweep verb pins a slower one); negative = no bound (still reapable by hand).
--files string — File numbers to size: a comma list and/or ranges, e.g. “2,19,50-59” (costs one single-file census per named file). Unset = every file with a data root, which sweeps the WHOLE instance census (~15 min class, run-lock held).
--cap float — Fit the estimate against a cap in GiB; exit 3 if the selection exceeds it. 0 = report size with no cap.
--top int 15 How many of the largest files to list (0 = all of them — uniform across verbs, F11). Render only; the totals always cover the whole selection.
--page-size int 200 Census page size (round-trip count only; the sweep is lossless).

Typed refusals: BAD_FILES · INCOMPLETE · OVER_CAP.

Inspect

Section titled “Inspect”

Dictionary and catalog reads: schema, the walked census, explain.

export

Section titled “export”

Write the data dictionary to disk as JSONL plus a manifest, for analysis away from the engine. The manifest records WHICH instance it came from, at what FileMan version, what was requested, and what was requested and not written.

engine access read.

Flag Type Default Description
--engine string vehu VistA engine profile to reach (vehu = YDB, foia = IRIS).
--lock-wait duration 30s How long to wait for the engine run-lock before refusing (0 = skip immediately when busy).
--timeout duration — Host wall-clock bound on ONE engine visit; a hung page is aborted engine-side, not just abandoned. Unset = the verb’s derived default (180s; a whole-instance sweep verb pins a slower one); negative = no bound (still reapable by hand).
--out (required) string — Directory to write into (created if absent). Receives dictionary.jsonl and manifest.json.
--files string — File numbers to export: a comma list and/or ranges, e.g. “2,19,50-59” (costs one single-file census per named file, for the injected record counts). Every named file is written together with its WHOLE sub-file tree (descent is recursive; naming a sub-file like 4.03 exports it directly). Unset = every file with a data dictionary plus, via descent, every sub-file — sweeps the WHOLE instance census (~15 min class, run-lock held).
--page-size int 200 Round-trip page size (count only; the walk is lossless).

Typed refusals: BAD_FILES.

census

Section titled “census”

The WALKED catalog of every file (table): honest record (row) counts with the stored header claim beside as an integrity signal, and sampled record sizes.

engine access read.

Flag Type Default Description
--engine string vehu VistA engine profile to reach (vehu = YDB, foia = IRIS).
--lock-wait duration 30s How long to wait for the engine run-lock before refusing (0 = skip immediately when busy).
--timeout duration — Host wall-clock bound on ONE engine visit; a hung page is aborted engine-side, not just abandoned. Unset = the verb’s derived default (180s; a whole-instance sweep verb pins a slower one); negative = no bound (still reapable by hand).
--file float — Catalog exactly one file by number; omit for every file on the instance.
--token string — Resume a prior census from its opaque token, verbatim.
--one-page bool — Fetch one bounded page and stop (prints the resume token).
--out string — Write every catalog row to this directory as JSONL + a manifest. –one-page is recorded as a NAMED incompleteness.
--pace duration — Politeness gap between the fold’s engine visits (e.g. 500ms) — host-side spacing for background sweeps.
--no-sizes bool — Skip the sampled record-size pass (sizes are estimates from the E-5 sampler; counts are always walked).
--per-patient bool — Also report each file’s records per patient (walked ÷ the patient file’s walked count).
--patient-file float 2 The file whose walked count is the –per-patient divisor (default #2 PATIENT).
--examined string — Candidates-examined budget per page (records + file entries; engine default 300000).
--elapsed string — Engine-time budget per page in ms (engine default 10000).
--bytes string — Emission budget per page in envelope bytes (engine default and ceiling 786432).

refs

Section titled “refs”

The reference map (foreign keys) around one file: what it points at, and what points at it — with –verify auditing FileMan’s pointed-to-by catalog against the fields themselves.

engine access read.

Argument Type Required Description
file float no File (table) number to map, e.g. 4 for INSTITUTION. Omit it and pass –all to sweep the whole dictionary.
Flag Type Default Description
--engine string vehu VistA engine profile to reach (vehu = YDB, foia = IRIS).
--lock-wait duration 30s How long to wait for the engine run-lock before refusing (0 = skip immediately when busy).
--timeout duration — Host wall-clock bound on ONE engine visit; a hung page is aborted engine-side, not just abandoned. Unset = the verb’s derived default (180s; a whole-instance sweep verb pins a slower one); negative = no bound (still reapable by hand).
--all bool — Sweep the WHOLE dictionary instead of one file: every pointer of every file at every depth, plus FileMan’s own pointed-to-by claims, reconciled against each other. This is the artifact §6.12’s offline closure is computed from — live recursion costs 1,294 dumps from a six-edge file and cannot complete #2 at all.
--out string — –all only: write every edge to this directory as refs.jsonl + a manifest (contract: docs/guides/refs-jsonl-contract.md).
--max-files int — –all only: stop after this many top-level subjects (0 = the whole dictionary). Recorded as a NAMED incompleteness, and a bounded pass makes NO catalog claim.
--token string — –all only: resume after this file number, verbatim from the prior pass.
--pace duration — –all only: politeness gap between subjects (e.g. 200ms) — host-side spacing for a background pass.
--direction both | inbound | outbound both Which half to build: outbound (references this file makes), inbound (references made TO it), or both.
--depth int 1 Follow references transitively to this depth (1 = direct only). Each additional file visited costs one round-trip.
--resolve bool — Name the far end of every reference — the pointing field inbound, the target’s name outbound. Costs ONE extra round-trip per file named.
--verify bool — Audit the inbound catalog against the independent field-level enumeration: every file it names is checked for a field that really points here.
--scope string — Comma-separated file numbers to additionally search for referencers the catalog does NOT list (the under-report direction). Without it that direction is not searched, and the verdict says so.
--page-size int 200 Dictionary-walk page size (round-trip count only; the sweep is lossless).

Typed refusals: BAD_SCOPE.

indexes

Section titled “indexes”

Inventory one file’s cross-references (indexes): both registers they are declared in, what each one stores, where the record id sits inside an entry, and whether its key IS the indexed column’s value — the measurements that say what may be looked up by key and what may not.

engine access read.

Argument Type Required Description
file float no FileMan file number, e.g. 44 for HOSPITAL LOCATION. Omit it and pass –all to sweep every file.
Flag Type Default Description
--engine string vehu VistA engine profile to reach (vehu = YDB, foia = IRIS).
--lock-wait duration 30s How long to wait for the engine run-lock before refusing (0 = skip immediately when busy).
--timeout duration — Host wall-clock bound on ONE engine visit; a hung page is aborted engine-side, not just abandoned. Unset = the verb’s derived default (180s; a whole-instance sweep verb pins a slower one); negative = no bound (still reapable by hand).
--all bool — Inventory EVERY top-level file in ONE engine-side pass (needs VSL1.061). Measured on vehu: 9,739 cross-references across 2,915 files in about two seconds — the per-file form costs 489 engine round trips for #2 alone. The key column is NOT measured at this scale and every row says so.
--kind string — List only cross-references of this kind (the classifier’s own word — regular, mumps, trigger, dangling, compound, record-level, and whatever else this instance carries). On one file this runs BEFORE the per-cross-reference probes, so a narrow list is a cheap one; under –all the engine has already measured every row, so it narrows the listing only.
--walkable bool — List only the cross-references a seek accepts. The others are still readable — see ‘find –raw’ — they just cannot be positioned by key.
--key-sample string — How many stored entries to read per seekable cross-reference when measuring whether its key IS the indexed field’s value (default 20; one file at a time only). 0 skips the measurement and every key cell says so. A larger sample raises the chance of catching a transform, and the length signals beside it catch the truncation a mismatch sample cannot.
--sample int — –all only: stored entries sampled per cross-reference (engine default 20). The sweep’s cost dial.
--page-size int — –all only: rows per engine page (engine default 2000).
--token string — –all only: resume a prior sweep from its opaque token, verbatim.
--one-page bool — –all only: fetch one bounded page and stop (prints the resume token). Recorded as a NAMED incompleteness in a written artifact.
--pace duration — –all only: politeness gap between the sweep’s engine visits (e.g. 500ms) — host-side spacing for background runs.
--out string — Write every row to this directory as indexes.jsonl + a manifest (consumer contract: docs/guides/indexes-jsonl-contract.md). On ONE file this is how –key-sample measurements are landed for –explain –indexes; under –all it lands the instance sweep.
--bytes string — One file only: emission budget per probe page in envelope bytes (engine default 786432).
--examined string — One file only: candidates-examined budget per probe page (engine default 75000).
--elapsed string — One file only: engine-time budget per probe page in ms (engine default 10000).

Typed refusals: BAD_KEY_SAMPLE · BAD_SAMPLE.

integrity

Section titled “integrity”

The instance-integrity census: the whole-instance sweeps — header claims vs walked truth, pointer resolution, declared-type grammar, the declaration-driven index audit (register + feed), hollow sub-records, the DD census, key uniqueness, and the full-depth sub-file descent — as counts with denominators per file (class, file, count, content-fold rows), never a pass/fail verdict.

engine access read.

Flag Type Default Description
--engine string vehu VistA engine profile to reach (vehu = YDB, foia = IRIS).
--lock-wait duration 30s How long to wait for the engine run-lock before refusing (0 = skip immediately when busy).
--timeout duration — Host wall-clock bound on ONE engine visit; a hung page is aborted engine-side, not just abandoned. Unset = the verb’s derived default (180s; a whole-instance sweep verb pins a slower one); negative = no bound (still reapable by hand).
--to float — Bound every walk to file numbers <= this (a dev/smoke run) — the artifact records the bound as a NAMED incompleteness; omit for the real, whole-instance audit.
--pace duration — Politeness gap between the audit’s engine visits (e.g. 500ms) — host-side spacing for background runs.
--out string — Write every audit row to this directory as JSONL + a manifest — the committed-artifact form the baseline/delta comparison reads.

integrity-compare

Section titled “integrity-compare”

Compare an integrity artifact against a named expectation, OFFLINE: a prior committed run of the same instance (any row difference is the red delta outcome) and/or the shipped-state ledger (one-sided excess is the attention outcome, never red). Speaks four pinned outcome words: clean, delta, attention, stopped.

Argument Type Required Description
subject string yes The artifact under comparison — a directory ‘v db integrity –out’ wrote (integrity.jsonl + manifest.json). Its checksum is verified before any verdict.
Flag Type Default Description
--base string — The named expectation: a prior committed integrity artifact of the SAME instance. Any row difference is the delta outcome (red), reported per (class, file, sub, value) row with this base’s identity beside the verdict.
--assert bool — The –base is an explicit assertion — a deliberately edited expectation. Its checksum is not verified, and the verdict labels it an assertion rather than a committed run.
--ledger string — The shipped-state ledger (baselines/integrity/ledger.jsonl): the cross-build floor. One-sided excess is the attention outcome — standing local damage, reported and NEVER red.

Typed refusals: COMPARE_INPUT · DELTA · STOPPED · WRONG_INSTANCE.

integrity-report

Section titled “integrity-report”

Explain one integrity artifact’s pointer findings by TARGET (VD-D109): dangling mass joined to each target file’s own header-ledger row — a header-divergent target is ONE finding with its mechanism shown, a healthy target is the class worth eyes, with the source list attached either way — plus the malformed split (type-history vs live-resolving), which has no target to attribute.

engine access read.

Argument Type Required Description
artifact string yes The integrity artifact to explain — a directory ‘v db integrity –out’ wrote. Its checksum is verified, and the live engine must declare the SAME instance the artifact measured (station), or the report refuses.
Flag Type Default Description
--engine string vehu VistA engine profile to reach (vehu = YDB, foia = IRIS).
--lock-wait duration 30s How long to wait for the engine run-lock before refusing (0 = skip immediately when busy).
--timeout duration — Host wall-clock bound on ONE engine visit; a hung page is aborted engine-side, not just abandoned. Unset = the verb’s derived default (180s; a whole-instance sweep verb pins a slower one); negative = no bound (still reapable by hand).

Typed refusals: COMPARE_INPUT · STOPPED · WRONG_INSTANCE.

bundle

Section titled “bundle”

Run a RUN SET — the committed declaration of the components a bundle is made of — writing each component to its own directory with its own manifest, and embedding the set that produced it. –explain reports what it WOULD export without reaching an engine.

engine access read.

Argument Type Required Description
set string yes The run set: a TOML file naming the components this bundle is made of, each a verb plus its arguments (sets/dd-bundle.toml is the committed one).
Flag Type Default Description
--engine string vehu VistA engine profile to reach (vehu = YDB, foia = IRIS).
--lock-wait duration 30s How long to wait for the engine run-lock before refusing (0 = skip immediately when busy).
--timeout duration — Host wall-clock bound on ONE engine visit; a hung page is aborted engine-side, not just abandoned. Unset = the verb’s derived default (180s; a whole-instance sweep verb pins a slower one); negative = no bound (still reapable by hand).
--out string — Write the bundle here: one directory per component, each with its own manifest, plus bundle.json and a byte-identical copy of the set that produced it.
--group list — Run only the components in these groups (repeatable). Every component left out is named in the bundle record with the reason. Without it the whole set runs.
--explain bool — Report what this set WOULD export and exit, without reaching an engine or writing anything: every component, its group, its purpose, its verb and its resolved arguments — and, if the set has problems, all of them rather than the first.
--base string — A previous bundle directory to certify drift against, always NAMED — never a baseline the run finds for itself. Record and byte drops are reported; a per-key density collapse (a key that carried values there and carries none here) refuses the run at that component. Without it drift is recorded as unmeasured.

Typed refusals: BAD_BASE · BAD_EXPLAIN · BAD_GROUP · BUNDLE_INCOMPLETE · COMPONENT_REFUSED · NO_OUT · OUT · SET_READ · SET_UNRESOLVED.

selection

Section titled “selection”

The SELECTION object: which tables to extract, at any depth, with a projection and filter per table — compiled into the run set ‘v db bundle’ runs. Saved, diffable and re-runnable; not a query language.

engine access none.

catalog

Section titled “catalog”

The VistA data catalog: build it offline from a certified bundle plus an integrity capture (one entry per table — structure, volume and condition planes, derived package attribution with its rule, search index embedded), then browse and search the artifact without an engine.

engine access none.

packet

Section titled “packet”

The DELIVERY PACKET: the per-component manifest, the producer certification, the channel evidence stated verbatim, the selection’s lineage with every declared exclusion, the sized run, and the condition of the data — the same-session integrity audit’s rows scoped to exactly what was extracted, read against the shipped-state floor. Counts over denominators; the packet never scores or judges.

engine access none.

Flag Type Default Description
--bundle (required) string — The extraction this packet describes: a directory ‘v db bundle –out’ wrote. Its set, per-component manifests and certifications are read and bound by digest.
--audit (required) string — The whole-instance integrity capture measured in the SAME SESSION as the extraction (a directory ‘v db integrity –out’ wrote). Its rows are scoped to the tables that were read; an audit measured before the extraction refuses.
--ledger (required) string — The shipped-state ledger (baselines/integrity/ledger.jsonl): the cross-build floor the scoped rows are read against. One-sided excess is reported as attention and is never red.
--sizing string — The sizing report for this run (‘v db selection size –out’), carried by digest with its interval and every prefix-sampled row’s declaration. Without it the packet names the absence rather than passing over it.
--session-window duration 1h How long after the extraction finished its condition rows may still be measured. The applied bound is stated in the packet; an audit outside it refuses rather than being described as same-session.
--out string — Write the packet here as JSON, exactly as the machine face renders it.

Typed refusals: OUT · PACKET_GRAIN · PACKET_PIN_MOVED · PACKET_SESSION · PACKET_STALE_AUDIT · PACKET_STOPPED.

Data

Section titled “Data”

The data plane: bounded, resumable reads with a completeness block on every page.

rows

Section titled “rows”

One bounded page of a file’s records (rows) walked in row-id order — the population is the walk, never a stored list, so nothing is missed because an index was stale (completeness block on every page).

engine access read.

Argument Type Required Description
file float yes FileMan file number, e.g. 200 for NEW PERSON.
Flag Type Default Description
--engine string vehu VistA engine profile to reach (vehu = YDB, foia = IRIS).
--lock-wait duration 30s How long to wait for the engine run-lock before refusing (0 = skip immediately when busy).
--timeout duration — Host wall-clock bound on ONE engine visit; a hung page is aborted engine-side, not just abandoned. Unset = the verb’s derived default (180s; a whole-instance sweep verb pins a slower one); negative = no bound (still reapable by hand).
--fields string — Projection: ‘;’-separated field numbers, or ‘*’ (engine default: all top-level).
--tier external | internal | raw — Projection tier (engine default external).
--where list — Row filter ‘ ’ (repeatable = AND). Ops: = ’= > < >= <= contains starts bound ’bound. Stored fields only, evaluated on the INTERNAL value (a pointer takes an IEN); rejected candidates stay charged to examined and show in filtered.
--parent string — Scope a SUB-file read to one multiple instance: the parent-record IENS, child-first with its trailing comma (‘999996,’ one level up; ‘d1,d0,’ two). For a nested-root file (#1.1) the one piece is the branch file number. Without it, a direct sub-file of a top-level parent pages the whole depth walk (rows keyed by emission ordinal, each carrying its full iens).
--with-multiples bool — Read each record WITH its sub-records: every non-word-processing multiple is projected inline under its field number, recursively, each sub-record carrying its own iens. Without it a ‘*’ read is flat and declares which multiples it left out. A record whose subtree exceeds the bytes budget becomes a typed TREESIZE row naming the record, the multiple and the paged alternative — never a silent trim.
--iens list — Read exactly these records, in the order given, instead of walking the file: a comma-separated list (repeat the flag to add more). Rows come back in SUPPLIED order, a repeated IEN is served per request (visible as emitted over distinct), and every IEN with no record is named in ‘misses’ rather than dropped. One paged conversation instead of one round trip per record: measured 253 ms/record through a get loop against ~25 ms/record paged.
--iens-file string — Read the record list from a file instead of –iens: one IEN per line (a comma-separated run on a line works too), blank lines skipped. ‘-’ reads standard input, which is how a pointer list from another read feeds straight in.
--ids bool — Attach a reference map to every row: for each pointer (foreign key) field, the file and record it names, plus a ‘ref’ that ‘get –ref’ reads back. A variable pointer resolves PER RECORD from its stored global root; a root the dictionary does not declare is resolved by asking which file owns it (marked resolvedBy:root), and named unresolved — never guessed — when no file claims it. Free on –tier internal (the values are already record numbers); on the default external tier it costs ONE extra internal projection of the reference fields per page.
--explain bool — Report what this read WOULD do and exit, without reading a data page: its population, which predicate each index can position, the cost class, and the command to run instead. Two bounded dictionary reads of this file; never a sweep.
--census string — –explain only: a census artifact (census.jsonl) to read this file’s record count from. The count is never estimated — it comes from a named artifact or it is reported unmeasured.
--indexes string — –explain only: an index artifact (indexes.jsonl from ‘v db indexes –key-sample N –out DIR’) to read the KEY measurements from. Without it every index is order-only, because whether a key IS the field’s value is the one fact a dictionary read cannot supply.
--profile string — –explain only: a fields-profile artifact (fields-profile.jsonl) — a predicate on a column measured at zero bound records is a guaranteed-empty walk, said before the walk.
--token string — Opaque continuation token from the prior page, passed back verbatim.
--out string — Write EVERY row to this directory as JSONL + a manifest, walking the file to exhaustion instead of returning one page. The manifest carries the merged completeness block, so a truncated artifact says so.
--max-pages int — Safety bound on the –out walk (0 = unbounded). Hitting it is recorded as a NAMED incompleteness, never a silent stop.
--pace duration — Politeness gap between the –out walk’s engine visits (e.g. 500ms) — host-side spacing for background extracts against a live instance; every page stays bounded regardless.
--max string — Rows budget (page size; engine default 4000).
--bytes string — Page payload byte budget (engine default 786432).
--examined string — Candidates-visited budget for the page (engine default 75000).
--elapsed string — Engine-time budget for the page in ms (0 is legal: stop after the first candidate; engine default 10000).

Typed refusals: BAD_IENS · BAD_MAX.

get

Section titled “get”

One record (row) by its IEN (row id), byte-exact — .5 is a real IEN, not a typo.

engine access read.

Argument Type Required Description
file float no FileMan file number, e.g. 200 for NEW PERSON.
